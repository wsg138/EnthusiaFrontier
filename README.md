# EnthusiaFrontier

EnthusiaFrontier is a Leaf/Paper world-frontier management plugin for Enthusia. It is designed to let the usable world extend beyond a pregenerated core without requiring the entire border to be pregenerated or permanently stored.

Development is tracked on feature branches and pull requests. See `docs/SPECIFICATION.md` and `docs/ARCHITECTURE.md` on the active implementation branch for the complete design.
